## ✦ Getting Started

Clone this repository:

```bash
git clone https://github.com/malvinzx/Portofolio.git
```

Enter the project directory:

```bash
cd Portofolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
